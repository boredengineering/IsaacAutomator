# Session Memory: Offline structural evidence graph MVP

## Summary

The user authorized implementation of the researched graph plan. Added a working
optional offline structural MVP, not the complete first-release roadmap.
Entry point: `./knowledge-graph`; documentation and executed-check record:
`src/knowledge_graph/README.md` and `src/knowledge_graph/ACCEPTANCE.md`.

## Decisions & Rationale

- Keep deployment Python, Terraform, Ansible, Dockerfile, existing test runner,
  agent configuration and VS Code settings unchanged. No deployment, service
  startup, commit or push. Graph dependencies are isolated in
  `$HOME/.cache/isaacautomator-graph/venv`, Python 3.12, hash-locked separately.
- Explicit reviewed public file policy, checked nofollow reads and whole-file
  quarantine precede indexing. Existing Neo4j/private/state/credential files are
  excluded; protected paths/content/digests are not individual graph records.
- Real Landlock + default-deny seccomp confines parsing and RDF validation after
  trusted imports. Bounded pipes, minimal environment, closed inherited FDs,
  CPU/memory/time limits; no unsafe fallback.
- Canonical RDF 1.1 explicit Claim occurrences with PROV-O and local SHACL;
  one-way derived MultiDiGraph retains parallel evidence and typed terms.
  Static support never means an executed or observed deployment succeeded.
- Pinned iaclens raw-source/API review found pre-output identity loss and external
  reads incompatible with required contracts. No upstream code copied or package
  installed; use narrow AST/PyYAML/python-hcl2 adapters instead. This is not an
  upstream runtime benchmark.

## Discovered Gotchas & Caveats

- Landlock does not revoke inherited writable files. Worker file-backed stdout
  was correctly rejected; parent now drains bounded pipes instead.
- Persisted manifests omit sources. Freshness must validate canonical manifest
  and coverage identity without requiring cached full source text.
- Reload current policy after work, not only once before it: an old in-memory
  policy dictionary misses revocation during extraction/query/validation.
- Typed path segments avoid literal-dot/bracket/slash key identity collisions;
  full source spans distinguish nested Python lookups sharing a start position.
- Conservative quarantine withholds legitimate modules/profiles containing
  sensitive identifier mentions. The graph cannot yet establish complete profile
  transport; workstation.demos returns unknown, not "unused".
- RDFLib emits upstream TriG deprecation warnings. Existing Textual tests emit
  timing/resource warnings. No claim of an end-to-end latency/token benefit or
  live cloud/GPU verification was made.
- Detailed temporary acceptance data: `/tmp/isaacautomator-graph-acceptance.json`;
  not durable. Re-run commands/tests before relying on counts or freshness.
