# Session Memory: Architectural Critique: Python Editable Bridge vs Directory Symlinks with Reversible Unlink Reset

## Summary
In this design and refinement session, we addressed the pitfalls of modifying git submodules directly:
1. **Architectural Tradeoff**:
   - **Strategy A (Non-Invasive Python Editable Bridge - Recommended)**: Uses standard `pip install -e` in the active environment without creating filesystem symlinks inside `submodules/`, keeping the Git working tree 100% clean with zero `typechange` pollution.
   - **Strategy B (In-Place Symlinking - Opt-In)**: Replaced with safe, atomic symlinks.
2. **Reversibility Guaranteed**:
   - Built `./bin/isaac-installer arena submodules unlink` (or `restore-pinned`) to safely strip any symlinks and check out exact upstream pinned submodule commits without data loss.
3. **Plan Updated**: Documented the comparison matrix in Section 5.4 of `isaac-install-plan.md`.
