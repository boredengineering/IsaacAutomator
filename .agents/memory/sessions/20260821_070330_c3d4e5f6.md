# Session Memory: Extensive Research & Production Engineering for Dual-Remote Fork Topology & Programmatic Forking

## Summary
In this research and implementation session, we engineered the programmatic GitHub fork verification and Dual-Remote Topology engine:
1. **GitHub CLI (`gh`) Integration**:
   - Researched and codified automated detection via `gh repo view` and `gh api`.
   - Enabled programmatic fork instantiation under both individual user accounts and organizations (`--org <org>`).
2. **Dual-Remote Git Protocol**:
   - `origin`: Personal fork repository (`https://github.com/boredengineering/IsaacLab.git` or SSH).
   - `upstream`: Canonical NVIDIA repository (`https://github.com/isaac-sim/IsaacLab.git`).
   - Push protection: Unconditional `remote.upstream.pushurl PUSH_DISABLED_CANONICAL_UPSTREAM`.
3. **CLI Operations**:
   - Added `lab fork <owner/repo>` and `lab remotes` subcommands to `isaac-installer`.
