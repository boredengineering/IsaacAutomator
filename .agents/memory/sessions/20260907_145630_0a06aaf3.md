## Decisions & Rationale
- **7-Tier Progressive Testing Hierarchy**:
  - Tier 1: Static syntax (`ansible-playbook --syntax-check`) and linting (`.ansible-lint`).
  - Tier 2: Unit test assertions on parameter-to-inventory mapping (`deployer.test.py`).
  - Tier 3: Local ephemeral Docker simulation (`-c docker`) for non-GPU roles without cloud billing.
  - Tier 4: Two-pass idempotency verification (Pass 1 apply, Pass 2 assert `changed=0`).
  - Tier 5: Speculative dry-runs via CLI (`./deploy-gcp --dry-run`).
  - Tier 6: Surgical cloud re-runs (`--existing run_ansible` and targeted tags).
  - Tier 7: In-workstation state verification (`/usr/local/bin/isaac-verify-state`).
- **Tag Standardization**: Applied explicit role tags in `roles/isaac-workstation/meta/main.yml` (`__auth`, `__conda`, `__hardware_teleop`, `__gr00t`, `__lerobot`, `__state_ledger`, `__verify`) so operators and CI can test individual roles without executing the full 45-minute orchestration.
