# Session Memory: DevContainer Git & GitHub Authentication Strategy (Pattern B)

## Summary
Investigated and resolved the Git and GitHub CLI authentication disconnect inside the Isaac Automator DevContainer. Researched community best practices, evaluated 5 authentication patterns, adopted **Pattern B** (persistent Docker named volume + setup lifecycle hook), updated `.devcontainer/devcontainer.json` and `.devcontainer/setup.sh`, authored the comprehensive reference doc `.agents/references/devcontainer/auth-strategy.md`, and indexed all references.

## Decisions & Rationale
- **Adopted Pattern B (Persistent Docker Named Volume + Hook)**:
  - Added `"source=isaac-gh-config,target=/root/.config/gh,type=volume"` to `.devcontainer/devcontainer.json`.
  - Added `gh auth setup-git` invocation to `.devcontainer/setup.sh` (executed once during container creation/startup).
  - *Rationale*: Protects credentials across container rebuilds, isolates state from host filesystem ownership issues, and ensures Git uses `gh auth git-credential` instead of triggering VS Code's host bridge prompts.
- **Evaluated and Rejected `.bashrc` Execution of `gh auth setup-git`**:
  - *Rationale*: `gh auth setup-git` modifies persistent configuration files (`~/.gitconfig`). Running disk write operations on every new subshell/terminal prompt is an anti-pattern; placing it in `setup.sh` provides deterministic, zero-latency one-time configuration.

## Discovered Gotchas & Caveats
- **VS Code Credential Helper Interception**: VS Code automatically injects its own JS helper into `/root/.gitconfig` and `/etc/gitconfig` on container attach. Running `gh auth setup-git` writes `credential.https://github.com.helper = ""` to reset VS Code's helper, followed by `!gh auth git-credential`.
- **Host Bind-Mount Fragility in Cloud Environments**: Mounting `${localEnv:HOME}/.config/gh` directly fails on clean-slate cloud VMs (where no host GitHub session exists) and across non-root user setups (`root` vs `ubuntu`/`vscode`). Named volumes avoid these host dependencies.
