# Session Memory: Isaac Sim 6.0 setup_conda_env.sh Compatibility Symlink & Omniverse Kit Discovery

## Summary
In this session, we resolved the Isaac Sim 6.0 environment export discovery issue:
1. **Root Cause**: In Isaac Sim 6.0 standalone binaries, NVIDIA renamed `setup_conda_env.sh` to `setup_python_env.sh`. When `isaaclab.sh` runs, it checks for `_isaac_sim/setup_conda_env.sh`, and if missing, warns and fails to export Isaac Sim PYTHONPATH and Carbonite library paths.
2. **Automated Compatibility Shim**:
   - `lib/modules/isaacsim.sh`, `lib/modules/isaaclab.sh`, and `lib/core/state.sh` now automatically create `ln -sf setup_python_env.sh setup_conda_env.sh` inside the Isaac Sim directory.
