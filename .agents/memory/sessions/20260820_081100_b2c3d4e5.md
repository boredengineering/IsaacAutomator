# Session Memory: Developer Fork Workflows, Atomic Multi-Engine Switching, and NVMe/LVM Bare-Metal Storage

## Summary
In this session, we engineered critical developer-first and bare-metal capabilities into `isaac-installer`:
1. **Fork + Upstream Git Remote Topology**: Seamless support for personal repository forks (`--isaaclab-repo`, `--arena-repo`, `--lerobot-repo`) with automated `origin` (push) and `upstream` (sync) wiring.
2. **GitHub Desktop UI Integration**: Automatic discovery of `~/Documents/GitHub` and CLI registration (`github-desktop --add <path>`).
3. **Multi-Version & Custom Source Build Engine Registry**: POSIX atomic `rename()` symlink switching with 0.1s swap time and automated rollback guard.
4. **NVMe CLI & LVM Storage Subsystem**: Deep detection and benchmarking of multiple NVMe SSDs and LVM volume groups across `doctor`, `plan`, and `test`.

## Key Architectural Decisions

- **POSIX Atomic `mv -Tf` Symlink Staging**:
  - Instead of `rm -f _isaac_sim && ln -s ...` (which introduces a race condition and crashes background processes), we stage to `_isaac_sim.tmp.$$` and atomically rename over `_isaac_sim`.
- **Smart Path & Repository Discovery**:
  - Probes `~/Documents/GitHub/*/<repo>`, `~/Documents/GitHub/<repo>`, `~/workspace/<repo>`, and `~/<repo>`. If an existing clone is found, it is adopted immediately without re-downloading.
- **Bare-Metal Multi-NVMe Strategy**:
  - Discovers NVMe drives via `nvme-cli` or `/sys/block/nvme*`.
  - Added `nvme-cli`, `lvm2`, `smartmontools`, `fio`, and `iotop` to the base development toolchain.

## Files Created & Updated
- `lib/core/git_workspace.sh`: Repo discovery, dual-remote fork configuration, and GitHub Desktop registration.
- `lib/core/detect.sh`: Multi-NVMe storage discovery, LVM volume groups, CPU/RAM topology, and process lock detection.
- `lib/modules/dev_tools.sh`: Added `nvme-cli`, `lvm2`, `smartmontools`, `fio`, `iotop`.
- `lib/modules/isaacsim.sh`: Multi-version engine discovery and custom source build validation.
- `lib/modules/isaaclab.sh` & `lib/modules/isaaclab_arena.sh`: Workspace path resolution, shallow depth-1 submodule cloning, and fork remote wiring.
- `bin/isaac-installer`: Expanded `doctor`, `plan`, and `test` to cover 13 distinct verification subsystems and storage topology cards.
