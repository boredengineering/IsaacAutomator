# Session Memory: Universal Bare-Metal Isaac Installer & Blackwell Workstation Probe

## Summary
Designed, implemented, and verified the **`isaac-installer`** project in `.agents/references/isaac-installer/` for automated bare-metal provisioning on fresh Ubuntu 22.04 LTS physical workstations. Built hardware, Blackwell architecture, multi-GPU, and display diagnostic probing tools. Tested on live bare-metal host with an **NVIDIA RTX PRO 6000 Blackwell Workstation Edition (96GB VRAM)**, validating driver requirements (v595.84 >= 570) and X11 session compliance.

## Decisions & Rationale
- **Two-Tier Ground-Truth Idempotency**: Each module inspects live hardware and system files before taking action, avoiding re-downloads of 15GB archives or redundant reboots when components already exist.
- **Blackwell GPU Auto-Detection**: Added GPU architecture mapping (`detect_gpu_architecture`) to enforce driver `>= 570` on Blackwell (RTX 50xx / GBxxx) while supporting legacy Ada/Ampere on 535/550.
- **Physical Desktop vs Headless Separation**: Remote streaming is strictly disabled by default (`--stream` opt-in). Native X11 monitor configurations are preserved without generating dummy virtual EDIDs.
- **Full Developer Stack**: Integrated Docker CE, NVIDIA Container Toolkit (`nvidia-ctk`), GitHub Desktop, and VS Code into [`lib/modules/dev_tools.sh`](file:///workspaces/IsaacAutomator/.agents/references/isaac-installer/lib/modules/dev_tools.sh).
- **Two-Phase DevContainer Integration**: Build-time packages in `Dockerfile` (for zero runtime network delay) + runtime configuration bridge in `setup.sh` (preventing mount shadowing).

## Discovered Gotchas & Caveats
- **Bash Arithmetic Exit Bug**: `((idx++))` under `set -e` returns exit code 1 when `idx=0`, causing bash scripts to silently terminate on the first loop iteration. Fixed by replacing with `idx=$((idx + 1))`.
- **GDM Wayland Incompatibility**: Ubuntu 22.04 default Wayland causes Omniverse Kit Vulkan swapchain jitter/crashes; the installer automatically enforces `WaylandEnable=false` in `/etc/gdm3/custom.conf`.
