# Session Memory: Native Ansible Replication of Isaac-Installer Capabilities

## Summary
Natively replicated the modern bare-metal capabilities of `isaac-installer` directly into idiomatic Ansible roles in `src/ansible/roles/`. Created 6 new roles (`roles/conda`, `roles/auth`, `roles/hardware-teleop`, `roles/gr00t`, `roles/lerobot`, `roles/state-ledger`), enhanced existing roles (`roles/system`, `roles/isaacsim-source`, `roles/isaaclab-source`, `roles/isaaclab-arena-source`, `roles/demos`), wired all dependencies into `roles/isaac-workstation/meta/main.yml`, added startup self-healing hooks to `autorun.yml`, updated Python demo config registries, and verified 100% test pass rate across all 62 unit tests and Ansible playbook syntax checks.

## Decisions & Rationale
- **Native Implementation over Script Synchronization**: Rather than wrapping installer shell scripts, everything was natively translated into declarative Ansible tasks and Jinja2 templates. This unleashes Ansible's unique cloud strengths: agentless execution via SSH/IAP, native idempotency, life-cycle granular tagging (`__autorun`, `on_stop_start`, `skip_in_image`), and seamless pre-baking into HashiCorp Packer golden images (`image-gcp`, `image-aws`).
- **Runtime Isolation with Conda & CLI Shim**: Created `roles/conda` providing `/usr/local/bin/isaaclab-env` CLI shim, Vulkan ICD dynamic manifest hook (`activate.d/vulkan_icd.sh`), and CP312 PYTHONPATH leak cleanup (`deactivate.d/cleanup_pythonpath.sh`).
- **Decoupled Foundation Model Stack**: Created `roles/gr00t` with ZeroMQ systemd policy serving on port 5555 and `roles/lerobot` with video codec dev dependencies and dataset visualizer CLI wrapper.
- **Persistent State Ledger & Self-Healing**: Created `roles/state-ledger` writing `/home/{{ ansible_user }}/.isaac-state.json` (and mirrored to `.isaac-installer/state.json`) with automated repair script `/usr/local/bin/isaac-verify-state` hooked into VM boot lifecycle in `autorun.yml`.
