# Session Memory: CLI --demo Option & Modal Dismissal with 'q' in isaac9s

## Summary
Resolved two critical bugs in the CLI and Textual TUI (`isaac9s`):
1. **`no such option: --demo`**: `DeployCommand` only registered `("--demos",)`. When `isaac9s` or users passed `--demo <name>`, Click failed with an error. Added `demos_callback` supporting both `--demos` and `--demo` (single flags, multiple flags `--demo A --demo B`, and comma-separated `--demos A,B`), normalizing to a clean string. Updated `app.py` to format as `--demos <list>`.
2. **Cannot close modal or raw inline code with `q`**: In Textual, `ModalScreen` instances truncate the binding chain, preventing unhandled keys from reaching `App`. Since modals lacked a `q` binding, users inspecting workstations or viewing raw Terraform/Meta state (`t`) were trapped and unable to close the view or exit `isaac9s` with `q`. Added `Binding("q", "dismiss_modal", "Close")` across all modals (`WorkstationInspectorModal`, `DeployWorkstationModal`, `RemoteDesktopModal`, `CloudAuthBridgeModal`).
3. **Input escape un-focus**: Updated `action_handle_escape` in `Isaac9sApp` to blur active focused inputs (`self.focused.blur()`), restoring navigation hotkeys.
4. **App helper aliases**: Added `open_deploy_modal`, `open_inspector_modal`, `open_auth_modal`, and `open_connect_modal` to `Isaac9sApp` to avoid `AttributeError` from panes.

## Key Changes
