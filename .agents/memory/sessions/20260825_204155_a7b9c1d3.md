## 1. Summary of Updates

1. **Proved Why Hardcoded User Build Args are Anti-Patterns**:
   - **DevContainer Specification Invariant**: Breaks portability across developers and CI runners; hardcoding a specific username (`tarfy`) breaks non-tarfy environments.
   - **Shell Property vs Environment Variable**: `$UID` in POSIX bash is a read-only shell variable, not an exported environment variable. `${localEnv:UID}` evaluates to null/empty without manual export.
   - **Omniverse Kit Internals**: Isaac Sim's Carb/Nucleus and Vulkan cache directories are pre-configured; mutating root ownership via build args breaks Omniverse runtime socket permissions.
   - **Standard Automated Remapping**: Modern devcontainers handle user remapping automatically via `"updateRemoteUserUID": true`.

2. **Cleaned up `physical-ai_agents.md`**:
   - Removed `"args"` block with `USER_NAME`, `USER_UID`, `USER_GID` from `devcontainer.json`.
   - Removed custom user creation from `Dockerfile` to maintain standard, portable NGC image compatibility.
