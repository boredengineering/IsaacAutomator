# Session Memory: Exhaustive Mental Model & Fix for Fork Export Variables, boredengineering Namespace, and GitHub Desktop GUI Bridge

## Summary
In this session, we systematically diagnosed and fixed the chain of issues affecting fork detection, hierarchy migration, and GitHub Desktop tracking:
1. **Unexported Config Variables**: Discovered that `ISAACLAB_REPO`, `ARENA_REPO`, `LEROBOT_REPO`, and `WORKSPACE_DIR` were missing from the `export` statement in `lib/core/config.sh`. This caused child subshells in `audit_workspace_drift` to see empty variables and fall back to the official upstream rather than the personal fork.
2. **boredengineering Namespace Alignment**: Updated `default-profile.yaml` and `full-ecosystem.yaml` to use your exact GitHub organization namespace: `boredengineering/IsaacLab` (`https://github.com/boredengineering/IsaacLab`).
3. **GitHub Desktop GUI Bridge**: Fixed `register_github_desktop_repo` to inject `$DISPLAY`, `$XAUTHORITY`, and `$DBUS_SESSION_BUS_ADDRESS` when called via `sudo`, allowing the Electron app to properly register newly migrated directories.
