# Session Memory: Eliminate Git Dubious Ownership and Safe.Directory Blockers in Sudo Remote Re-Wiring

## Summary
In this session, we resolved the issue causing `UPSTREAM_MISSING` drift to persist after `repair`:
1. **Root Cause**: When running `sudo ./bin/isaac-installer repair`, root git invocations on user-owned repositories were blocked by Git's `safe.directory` security feature (`dubious ownership`), causing remote checks to fail silently.
2. **Fix**:
   - Added automatic `git config --global --add safe.directory "$repo_dir"` for both root and target user.
   - Refactored `get_repo_info` to query `git config` directly under target user context.
   - Added `clean_url` normalization (stripping trailing slashes and `.git` case-insensitively).
   - Ensured `repair` runs `git remote set-url` or `git remote add` reliably.
