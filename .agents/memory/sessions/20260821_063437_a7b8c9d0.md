# Session Memory: Conda Base Plugin Entry Point Cleanup & Pydantic-Core Conflict Resolution

## Summary
In this session, we resolved the Conda base plugin entry point failure (`pydantic_core._pydantic_core`):
1. **Root Cause**: Commercial Anaconda auth and guide plugins (`anaconda-cloud-auth`, `conda-anaconda-tos`, `anaconda-channel-guide`) installed in Conda's `base` environment have incompatible Rust C-extensions (`pydantic-core`), triggering warnings whenever Conda CLI executes.
2. **Resolution**:
   - Removed broken/unneeded commercial auth plugins from `base` via `conda remove -n base anaconda-cloud-auth conda-anaconda-tos anaconda-channel-guide -y`.
   - Automated this cleanup in `lib/modules/conda.sh`.
