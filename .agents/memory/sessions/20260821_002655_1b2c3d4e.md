# Session Memory: Implementation of REPO_MISSING Drift Detection and Dynamic State Ledger Synchronization

## Summary
In this session, we resolved the edge case where missing repositories on disk were reporting false-positive "Zero drift":
1. **Root Cause**: `audit_workspace_drift` previously wrapped repository checks inside `if [[ -n "$lab_existing" ]]` without an `else` branch, causing completely absent repositories to be skipped silently.
2. **Dynamic State File Resolution**: Added `resolve_state_dir()` and `resolve_state_file()` so `~/.isaac-installer/state.json` is always resolved dynamically with the correct `$TARGET_HOME`.
3. **REPO_MISSING Detection & Self-Healing**: Added explicit `REPO_MISSING` drift detection and auto-provisioning for `IsaacLab`, `IsaacLab-Arena`, and `LeRobot`.
4. **Automated Ledger Snapshot**: Added `sync_state_ledger()` to write active commit hashes, remotes, and Conda environments to `state.json` upon completion of `repair`.
