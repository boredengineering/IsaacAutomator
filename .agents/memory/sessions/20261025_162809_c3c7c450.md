# Session Memory: Shared workstation connection contract and perfected GCP IAP flow

## Summary
Reconciled CLI and `isaac9s` around a single shared connection backend contract (`src/python/workstation_connection.py`), eliminating divergence and perfecting the private GCP workstation → Cloud IAP connection flow.

## Decisions & Rationale
- **Shared Connection Contract**: Implemented `WorkstationConnectionInfo` and `resolve_workstation_connection` in `src/python/workstation_connection.py` to authoritatively determine cloud type, IAP configuration, IP addresses, and protocol endpoints.
- **Fixed Fatal CLI `novnc` Bug**: When `enable_iap_only` is true on GCP, Terraform outputs an empty string for `isaac_workstation_ip`. Previously, `./novnc` aborted immediately on empty public IP before evaluating IAP. Moved IAP resolution to the top so private GCP VMs connect seamlessly via loopback tunnels.
- **Accurate Telemetry & Fleet Visibility in `isaac9s`**:
  - Enhanced `WorkstationBackend.get_deployments()` in `src/tui/backend.py` to identify GCP deployments (previously showed `UNKNOWN` cloud) and parse `iap_enabled`, `project`, `zone`, `instance_name`, and `private_ip`.
  - Private GCP VMs now display `IAP (Private)` or `IAP (10.x.x.x)` rather than `N/A`.
  - Maintained the security rule: local `.tfstate` snapshots are only read when `attachment == 'legacy-local'`, preventing stale local reads on remote backends.
- **Realistic Protocol Support in `RemoteDesktopModal`**:
  - Dynamic security posture: displays `Cloud IAP (Identity-Aware Proxy, Zero Public Ingress)` instead of hardcoded `/32 Caller IP Filter`.
  - Loopback endpoint resolution: displays `http://127.0.0.1:6080/vnc.html?resize=scale` and `nx://127.0.0.1:4000` for IAP.
  - Incompatible protocol guard: explicitly flags Sunshine as unsupported over IAP because Sunshine requires UDP, which Cloud IAP TCP forwarding does not support.
  - Supervised launch: launching noVNC in `isaac9s` spawns `./novnc <name>` as an actively supervised async background command, viewable in the `[3] Real-Time Logs` tab and cancellable with `[k]`.
