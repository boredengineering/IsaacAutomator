# Session Memory: Dynamic Detection of User's Miniconda/Anaconda and Native Environment Creation

## Summary
In this session, we refactored the Conda module to eliminate hardcoded `/opt/conda` paths.
1. **Dynamic Conda Discovery**: Automatically discovers the user's active Conda binary (e.g. `~/miniconda3/bin/conda`, `~/anaconda3/bin/conda`, `~/.conda`).
2. **Native Environment Creation**: Directly creates the named environment `isaaclab` inside the user's active Conda (`~/miniconda3/envs/isaaclab`) using unprivileged user permissions.
3. **Automatic Named Listing**: `conda env list` naturally displays `isaaclab /home/tarfy/miniconda3/envs/isaaclab` without needing manual `envs_dirs` modifications.
