# Session Memory: Self-hosted estimator trials

## Summary

User requested updating the roadmap and testing self-hosted open-source
alternatives until a viable option works. Updated the current cost status and
added Task 28S to `terraform-remote-backend-plan.md`. Ran isolated C3X,
TerraCost and IBM Cloud Pricing API trials; scope-screened OptScale/OpenCost/ACE.
C3X demonstrated a real self-hosted Azure estimate, but no candidate passed the
G4/Flex workload gate. No production integration was changed or declared ready.

## Decisions & Rationale

- Keep existing bounded Infracost adapter/UI intact; self-hosted architecture
  proof does not justify replacing it with incorrect G4 cost reports.
- C3X leads as a self-hosted CLI/API/PostgreSQL architecture: real Azure Key Vault
  import and USD 0.30 for 100,000 operations with outward access denied during
  estimation. Import used official Microsoft pricing with egress beforehand.
- TerraCost built and ran against MySQL using synthetic prices; no genuine GCP
  quote. Root MIT license has a BSL Terraform-fork dependency caveat.
- IBM stock build failed on unavailable private logger; disposable public-logger,
  Node/TS/type/Promise repairs built successfully. Native init still exits 1 at
  removed data-download command. A harness-imported official Azure record was
  served locally at USD 0.096/hour; backend-only, not estimator compatibility.

## Discovered Gotchas & Caveats

- Docker daemon could not see devcontainer `/tmp` bind paths. Trials used docker
  cp into isolated containers instead; no HOME/credential/state/socket mounts.
- C3X original `.tf.json` fixtures fail discovery. All four HCL projections
  returned zero VM/disk/GPU rates tagged live. Flex queries OnDemand; unsupported
  GPU/disk map toward T4/PD. G4 missing from backend synthesis whitelist. No valid
  G4 price was observed; trial DB had Azure prices only.
- C3X reference-region fallback is unsafe for strict regional pricing; accepted
  Azure trial explicitly set eastus. API-down probe failed instead of producing
  hosted fallback quote. Request log records targets, not all successful forwards.
- TerraCost returned top-level nil/zero despite invalid resources. GPU/Flex
  controls did not change its single compute component; ancillary resources
  were skipped. Synthetic seeded totals must never count as vendor pricing.
- No approved GCP pricing key was supplied; clarification timed out. No existing
  credentials were searched or used. API access alone will not fix model bugs.
