# Session Memory: Decoupled Standalone Workspace with Atomic Submodule Bridging for IsaacLab-Arena and Isaac-GR00T

## Summary
In this architecture and tooling session, we resolved the Submodule vs Standalone Workspace dilemma:
1. **Decoupled Architecture**: Enabled developing inside standalone repositories (`Isaac-GR00T`, `IsaacLab`, `IsaacLab-Arena`) with full Dual-Remote Git topologies, branch tracking, and push permissions.
2. **Submodule Bridging Engine (`lib/modules/isaaclab_arena.sh`)**:
   - `arena submodules status`: Audits submodule vs standalone commit alignment.
   - `arena submodules link-standalone`: Atomically swaps internal submodules (`submodules/IsaacLab`, `submodules/Isaac-GR00T`) for live symlinks to standalone developer workspaces, enabling instantaneous edit propagation.
   - `arena submodules restore-pinned`: Restores exact upstream pinned commit hashes for deterministic CI/CD and benchmark replication.
   - `arena play <task>` / `arena run <task>`: Direct CLI helpers for live Kit viewports and headless rollouts.
3. **Master Plan & Documentation**: Added Section 5.4 to `isaac-install-plan.md` and updated `README.md`.
