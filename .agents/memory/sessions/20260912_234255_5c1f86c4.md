## Gotchas and fixes

- Infracost 2.16.3 uses scan, not legacy breakdown flags; unknown legacy flags may
  be silently ignored. Old INFRACOST_API_KEY alone is insufficient.
- Parser/provider plugins are separate pinned executables; explicit plugin path
  disables installation. Native plugin handshakes were exercised.
- CLI telemetry lacks a generally verified privacy-off policy. Events are
  redirected to refused loopback, but hosted auth/run-parameter calls remain.
  Private input is deliberately rejected, even if pricing consent is supplied.
- Fixed FIFO/runtime read hangs, escaped JSON Flex detection, false region labels,
  recursive free-parent coverage loss, misleading unknown-to-savings comparisons,
  stale backend-config estimates and clipped production Profiles controls.
- Only typed global networks may omit location; only GCS bucket location gets
  regional case normalization. Unknown/mixed regions remain conservative.
