## Decisions & Rationale
- **Deterministic Remote State Bootstrap**: When `backend: gcs` and `bucket: "auto"` are configured, the deployer synthesizes an ambient deterministic bucket name `isaac-state-<hash>` and provisions it JIT before Terraform initialization.
- **Bucket Option Gate**: When `bucket` is empty/omitted, the deployer strictly defaults to local backend with zero network calls or cloud API requirements.
- **Submodule Handling in `public_git.py`**: Repositories with detached submodules (such as `IsaacLab-Arena`) are cloned using `--allow-submodules` so that detached source checkouts succeed without enforcing submodule recursion.
- **Git LFS Handling in Isaac-GR00T**: Git LFS binary pointer files for wheel dependencies (`torchcodec`) are materialized via `git lfs pull` prior to `uv sync` execution, preventing zip decompression errors during package builds.
- **Idempotent Public Git Checkouts**: Ansible `public-git` tasks check whether the target directory already exists and skip checkout to ensure safe re-entrant playbook executions.
