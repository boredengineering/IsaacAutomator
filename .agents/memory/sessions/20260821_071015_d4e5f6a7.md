# Session Memory: Smart Branch-Aware Sync Engine & Dual-Remote Upstream Rebase Protection

## Summary
In this session, we resolved the rebase conflict behavior and perfected the Dual-Remote Git workflow:
1. **Root Cause of Rebase Conflict**: The local repository was on a pinned release tag branch (`release/v3.0.0-beta2`). Rebasing an immutable release tag branch onto `upstream/main` (cutting-edge development HEAD) caused commit collisions on changelog and extension version files.
2. **Smart Branch-Aware Sync Engine**:
   - Upgraded `lab sync` in `lib/modules/isaaclab.sh` to distinguish between release tag branches (`release/v*`) and development branches (`main`, `feature/*`).
   - Added `lab sync --abort` to instantly recover from in-progress rebase conflicts.
   - Pinned release tag branches prompt the developer to use `lab switch <tag>` or switch to `main` before syncing.
