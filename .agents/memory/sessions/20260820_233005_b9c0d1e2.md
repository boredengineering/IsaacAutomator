# Session Memory: Fix Target Path Resolution for Desired Workspace Hierarchy Migration

## Summary
In this session, we fixed a logic flaw in `resolve_repo_dest_path()`:
1. Previously, `resolve_repo_dest_path()` short-circuited if an existing flat clone was found on disk, causing the drift detector to treat the flat clone as the target path.
2. We removed the short-circuit from `resolve_repo_dest_path()` so it strictly computes the **desired target path** (`~/Documents/GitHub/BoredEngineer/<Repo>`).
3. Added `resolve_active_repo_dir()` for commands that inspect the active clone.
4. Now, running `isaac-installer drift` on hosts with flat clones (`~/Documents/GitHub/IsaacLab`) correctly flags `PATH_MISLOCATED`, and `isaac-installer repair` moves them into `~/Documents/GitHub/BoredEngineer/` safely.
