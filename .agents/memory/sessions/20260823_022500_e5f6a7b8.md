# Session Memory: Milestone: NVIDIA Isaac-GR00T VLA Open-Loop Inference Verified & Dual-Model Architecture

## Summary
Successfully verified end-to-end execution of the NVIDIA Isaac-GR00T Physical AI foundation model (`nvidia/GR00T-N1.7-3B` + `nvidia/Cosmos-Reason2-2B` vision backbone). The 1.09B parameter DiT action diffusion model and 2.01B parameter vision-language encoder completed 25 inference steps over the DROID robotic manipulation trajectory dataset with a remarkable average inference time of 89.9 ms on the NVIDIA RTX PRO 6000 Blackwell Workstation (Action MSE: 0.00328).

## Key Discoveries & Architectural Decisions
1. **Dual-Model VLA Dependency**:
   - `nvidia/GR00T-N1.7-3B` does not operate in isolation; it dynamically instantiates `nvidia/Cosmos-Reason2-2B` as its System 2 visual-language perception backbone.
   - Both models require 1-click gated license authorization on Hugging Face.
   - Documented in Section 14.2 of `isaac-install-plan.md` and updated `gr00t.sh` to pre-cache both repositories.
2. **CLI Alignment**:
   - `standalone_inference_script.py` uses `--action-horizon` (default 8/16), not `--execution-horizon`.
   - Updated `gr00t infer` to forward arguments dynamically.
3. **Download Acceleration**:
   - Single-threaded Python `transformers` downloads frequently stall on 5+ GB safetensors files.
   - Using the Rust-accelerated `hf download` engine with `HF_HUB_ENABLE_HF_TRANSFER=1` and multi-threaded streams downloads 100% reliably in seconds.

## Performance Metrics (NVIDIA RTX PRO 6000 Blackwell)
