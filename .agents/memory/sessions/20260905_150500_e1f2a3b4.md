# Session Memory: Subprocess Hang Diagnosis, Process Cancellation Controls, and Codebase Architecture

## Summary
Diagnosed the root causes that made deployments and tests appear "stuck" inside `isaac9s`. Implemented unbuffered streaming execution, DEVNULL stdin decoupling, GCP ADC credential auto-recovery, a live process status badge, and an abort/kill mechanism. Provided comprehensive documentation of the codebase architecture for operator and developer debugging.

## Root Causes Diagnosed
1. **Missing Non-Interactive Arguments**: `deploy-gcp` prompts interactively on stdout whenever prompted flags are missing (`--ingress-cidrs`, `--project`, `--isaac-workstation-gpu-count`, `--isaacsim`, `--isaaclab`, `--isaaclab-arena`, `--no-upload`).
2. **Stdin Deadlock**: Click prompts without a trailing `\n`, causing `proc.stdout.readline()` to block indefinitely while Click waits for stdin from a raw Textual event loop.
3. **Missing ADC Credential**: GCP Application Default Credentials (`~/.config/gcloud/application_default_credentials.json`) were absent, triggering an interactive browser verification code prompt.
4. **Lack of Process Cancellation**: The operator had no UI badge indicating active PID/runtime, and no "Stop" button or keybinding to kill a hung background command.

## Key Changes
1. **Full Command Argument Injection (`src/tui/app.py`)**:
   - `on_deploy_submitted` now explicitly passes `--deployment-name`, `--instance-type`, `--profile`, `--existing replace`, `--ingress-cidrs 0.0.0.0/0`, `--isaacsim latest`, `--isaaclab latest`, `--isaaclab-arena latest`, `--no-upload`, and for GCP `--project <id>` and `--isaac-workstation-gpu-count 1`.
2. **Unbuffered Streaming & Stdin Decoupling (`src/tui/app.py`)**:
   - `run_async_command` now executes with `PYTHONUNBUFFERED=1`, `stdin=subprocess.DEVNULL`, `bufsize=1`, and unbuffered line reading via `iter(proc.stdout.readline, "")`.
   - Auto-detects and recovers GCP ADC credentials from `legacy_credentials/` if missing.
3. **Process Cancellation & Status Indicator (`src/tui/screens/logs.py`, `src/tui/app.py`)**:
   - Added `#proc-status-badge` (`● IDLE` / `● RUNNING (PID 12345)`) and `#btn-cancel-proc` ("Stop Process").
   - Added hotkey `k` and command palette aliases `:stop`, `:kill`, `:abort`, `:k` calling `action_cancel_running_process()`.
4. **Testing & Verification**:
   - Added automated tests in `src/tests/isaac9s.test.py` covering badge states and kill actions.
   - All 87 unit and integration tests passing (`PYTHONPATH=. ./src/tests/run_all.sh`).
