# Session Memory: Multi-Agent MCP & Skills Automation for Antigravity and Claude Code

## Summary
Diagnosed and resolved the root causes behind MCP servers and skills failing to load automatically upon container startup. Designed, implemented, and verified a cross-agent automated bootstrap lifecycle (`.devcontainer/setup.sh`) hooked into `postCreateCommand`. Consolidated 336 skills into `.agents/skills/`, eliminated broken symlinks and duplicate directories, and synchronized active configurations across Google Antigravity and Claude Code.

## Decisions & Rationale
1. **Dynamic DevContainer Setup Lifecycle (`.devcontainer/setup.sh`)**:
   - Implemented a path-agnostic bootstrap script running under `postCreateCommand`.
   - Populates Antigravity's `~/.gemini/config/mcp_config.json` directly from the repository's `.mcp.json`.
   - Configures `.agents/skills.json` to register both core Isaac Automator skills and all 335 NVIDIA skills.
   - Pre-approves and registers MCP servers (`terraform`, `playwright`, `ansible`, `gcp-cloud`) in `~/.claude.json` user scope for zero-prompt Claude Code execution.
   - Automatically installs the 335+ NVIDIA skills via `npx skills` if missing on fresh clone.
   - Installs Ansible collections (`community.docker`, `google.cloud`).
2. **Skill Consolidation**:
   - Restored and consolidated all 336 skills into `.agents/skills/` so symlinks in `skills/` resolve cleanly.
   - Removed the 51MB untracked duplicate `agent/skills/` folder.
3. **MCP Configuration Cleanliness**:
   - Removed the hardcoded non-existent `GOOGLE_APPLICATION_CREDENTIALS` path from `.mcp.json` to let `@google-cloud/gcloud-mcp` connect seamlessly using standard ADC discovery.

## Discovered Gotchas & Caveats
- **DevContainer Mount Shadowing**: Host bind mounts (`~/.gemini`, `~/.claude`) overwrite build-time Dockerfile configs at container start. All agent configs must be populated at runtime via `postCreateCommand`.
- **Claude Code Project Approval**: Repositories containing `.mcp.json` are marked `⏸ Pending approval` by Claude Code unless pre-registered at user scope in `~/.claude.json`.
