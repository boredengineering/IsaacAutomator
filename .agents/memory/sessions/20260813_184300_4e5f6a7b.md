# Session Memory: GCP Flex-start Integration & VM Cycling

## Summary
Integrated GCP Flex-start (Dynamic Workload Scheduler) into Isaac Automator across the Terraform infrastructure, Python Click CLI wrappers, native GCP start/stop lifecycle management, and a new VM cycling utility (`cycle-vm`) for resetting the 7-day maximum run duration.

## Decisions & Rationale
1. **Terraform Dynamic Scheduling**:
   - Updated `src/terraform/gcp/variables.tf` and `src/terraform/gcp/ovkit/variables.tf` to introduce `use_flex_start` (bool, default `false`).
   - Forwarded `use_flex_start` in `src/terraform/gcp/main.tf` to `module.isaac_workstation`.
   - Updated `src/terraform/gcp/ovkit/main.tf` with dynamic `scheduling` blocks for `FLEX_START` (`provisioning_model = "FLEX_START"`, `instance_termination_action = "STOP"`, `automatic_restart = false`, `max_run_duration { seconds = 604800 }`) and `STANDARD` while maintaining `on_host_maintenance = "TERMINATE"` for GPU compliance.
2. **CLI Parameter Binding**:
   - Added `--flex-start / --no-flex-start` in `deploy-gcp` (`DeployGCPCommand`) and mapped `use_flex_start` to `.tfvars`.
3. **GCP Lifecycle Management**:
   - Implemented `src/python/gcp.py` (`gcp_start_instance`, `gcp_stop_instance`, `gcp_get_instance_status`, `gcp_get_instance_last_start`, `gcp_get_instance_uptime_seconds`, `parse_iso_timestamp`).
   - Integrated GCP start/stop polling into `./start` and `./stop`.
4. **VM Cycling Command**:
   - Created `./cycle-vm` (and `./cycle-vm.sh`) to inspect `lastStartTimestamp`, safely parse ISO 8601 timestamps, and cycle VMs when uptime approaches 7 days (default threshold: 6.5 days / 156 hours).
5. **Documentation & Skills**:
   - Updated `.agents/skills/isaac-automator/deploy-workstation/SKILL.md`, `.agents/skills/isaac-automator/manage-lifecycle/SKILL.md`, and `README.md`.

## Discovered Gotchas & Technical Notes
- **GCP GPU Constraints**: `on_host_maintenance = "TERMINATE"` is mandatory on GCP whenever guest accelerators (GPUs) are attached, regardless of whether `FLEX_START` or `STANDARD` scheduling is used.
- **ISO 8601 Parser**: Trailing `Z` in Google API timestamps requires normalization (`.replace('Z', '+00:00')`) for Python `datetime.fromisoformat`.
