# Session Memory: Vulkan ICD Manifest Path Resolution & Isaac Lab 3.0 Multi-Visualizer Debugging

## Summary
In this session, we debugged why `--viz kit` failed to render the Omniverse UI:
1. **Root Cause**: `VK_ICD_FILENAMES` was hardcoded to `/etc/vulkan/icd.d/nvidia_icd.json` in the Conda activation hook. On Ubuntu Linux, NVIDIA proprietary driver manifests reside in `/usr/share/vulkan/icd.d/nvidia_icd.json`. Pointing to a non-existent `/etc` path caused Vulkan loader to fail with `loader_get_json: Failed to open JSON file` and `vkCreateInstance failed with ERROR_INCOMPATIBLE_DRIVER`.
2. **Code Resolution**:
   - Updated `lib/modules/conda.sh` to dynamically probe `/usr/share/vulkan/icd.d/nvidia_icd.json` and `/etc/vulkan/icd.d/nvidia_icd.json`, falling back to native Vulkan loader auto-discovery if unset.
