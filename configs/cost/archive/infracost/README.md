# Retired Infracost records — historical only

The user selected C3X for future development in a dedicated project. Infracost's
active IsaacAutomator integration has been removed. Nothing here is consumed by
the current Dockerfile, CLI or isaac9s; do not run the old installation commands.

`manifest.json` maps each original path to its byte-identical archived file and
SHA-256. `integration-guide.md` preserves the old README; its commands, relative
links, source paths and delivered-state claims refer to that earlier revision,
not current functionality. `VERIFICATION.md`, `verification.json` and
`core-review.json` preserve scoped historical evidence, not current test results.
`runtime.json` is retired version metadata, not an active dependency manifest.
`infracost-usage.example.yml` is the original public baseline used by prior trials;
native C3X mappings use different usage keys. Preserve the file for provenance,
not as a C3X configuration recommendation.

The removed source remains in Git history; no executable adapter/installer is
retained in this archive. Do not recreate old test targets from historical guides.
For current direction see [cost status](../../README.md) and its C3X plan links.
